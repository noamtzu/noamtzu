## How I work with clients
1. **A small, fixed first milestone.** One working feature, fix or integration in 2–3 days, so you can judge my work before committing more.
2. **Every change is a PR** with tests, a QA note and a rollback path. Nothing reaches your main branch without your review.
3. **Short written updates** at each step, and one question at a time when something is unclear.
